# Stream Player — for TCL TV (Model 55C6K)

An Android TV app that plays live streaming channels over wifi from any M3U/M3U8
playlist URL you provide. Built with Kotlin + AndroidX Media3 (ExoPlayer).

## Important note on "all channels"

No app can legally bundle every streaming network's content — each one (Netflix,
Disney+, ESPN, etc.) requires its own license and its own official app. This app
is a **player**: point it at an M3U playlist URL and it will list and play every
channel in that playlist. Use it with a playlist you have the rights to use, e.g.:

- A playlist your IPTV/cable provider gives you
- Public, free-to-air broadcaster streams
- Your own personal/home streaming setup

Do not point it at pirated or unlicensed playlists.

## What's included

- `MainActivity` — TV-friendly grid of channels (5 columns, remote-navigable)
- `PlayerActivity` — full-screen ExoPlayer (Media3) video playback with built-in
  transport controls, works over HLS/DASH/progressive streams
- `SettingsActivity` — enter/change the M3U playlist URL (press MENU on the
  remote from the home screen)
- `M3uParser` — parses standard `#EXTINF` M3U playlists (name, logo, group)
- Appears on the TV's Google TV / Android TV home launcher via the
  `LEANBACK_LAUNCHER` intent category

## Building the APK

You need Android Studio (free) or a machine with a JDK 17 + Android SDK.

### Option A — Android Studio (easiest)
1. Open this folder in Android Studio ("Open an existing project").
2. Let Gradle sync (it will auto-generate the missing wrapper jar).
3. Build → Build Bundle(s)/APK(s) → Build APK(s).
4. Find the APK at `app/build/outputs/apk/debug/app-debug.apk`.

### Option B — GitHub Actions (build in the cloud, no local install)
1. Push this project to a new GitHub repo.
2. The included workflow at `.github/workflows/build.yml` builds the APK
   automatically on every push, or manually via the "Run workflow" button.
3. Download the built APK from the workflow run's "Artifacts" section.

### Option C — Command line
```
./gradlew assembleDebug
```
(First run `gradle wrapper` once if `gradlew` has no wrapper jar yet — Android
Studio does this for you automatically on first open.)

## Installing on the TCL 55C6K over wifi

The 55C6K (Google TV) doesn't allow installing unknown APKs by default. Steps:

1. On the TV: Settings → System → About → click "Android TV OS build" ~7 times
   to unlock Developer options.
2. Settings → System → Developer options → enable "Unknown sources" / allow
   installs from your file manager or "Apps from Unknown Sources."
3. Easiest wifi-only method: install the **"Send Files to TV"** or
   **"Downloader"** app on the TV (from the Google Play Store on the TV), then:
   - Downloader: enter a direct URL to your APK (e.g. host it on Google Drive
     with a public link, or a simple local web server) and it downloads +
     installs it directly.
   - Alternative: use `adb install app-debug.apk` from a PC on the same wifi
     network (enable "Network debugging" in Developer options, then
     `adb connect <TV_IP>:5555`).
4. Launch "Stream Player" from the TV's app list, press MENU on first run to
   enter your playlist URL.

## Customizing

- Grid columns: change `GridLayoutManager(this, 5)` in `MainActivity.kt`.
- App name/icon: edit `strings.xml` / the `mipmap-anydpi-v26` and `drawable`
  icon files.
- minSdk is set to 23 for broad compatibility; the 55C6K's Google TV OS is
  well above that.
